# **App Name**: Pooja's Portfolio

## Core Features:

- Home Section: Display a brief introduction with her name, title, and links to contact, LinkedIn, and GitHub.
- About, Experience, Projects, Skills, Resume Sections: Display detailed descriptions of her work experience, projects, and skills with the appropriate links and downloadable resume.
- Contact Section: Implement a contact form and display contact information (email, phone number, location).

## Style Guidelines:

- Use a soft color palette with lavender, soft blue, and white as the primary colors.
- Accent color: Teal (#008080) for highlights and interactive elements.
- Implement a clean and modern layout with a focus on readability and user experience.
- Use smooth transitions and subtle animations to enhance the user experience.
- Ensure the website is fully responsive and optimized for mobile devices.
- Implement a light/dark mode toggle for user preference.
